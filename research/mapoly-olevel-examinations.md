# MAPOLY O’level examination catalogue

Researched 20 September 2026. This catalogue covers the examination names supported by the sources below; it is not confirmation of every examination accepted for the current admission session.

## Institution evidence

MAPOLY's legacy admission advertisement lists SSCE, NECO, WASC, GCE O’level and NABTEB in its National Diploma entry requirements:
https://mapolyng.com/apply/advert1.html

The page is historical, not a verified current-session policy. Attempts to retrieve https://mapoly.edu.ng/ and https://mapoly.edu.ng/web/ were unsuccessful. Programme thresholds and subject rules remain demonstration data. The catalogue should be confirmed with MAPOLY when current institutional materials become available.

## Labels used in the application

| Dropdown option | Stored board | Stored examination type |
| --- | --- | --- |
| WAEC — WASSCE / SSCE (School) | WAEC | School |
| WAEC — GCE O’level / WASSCE (Private) | WAEC | Private/GCE |
| WAEC — WASC (Legacy certificate) | WAEC | WASC |
| NECO — SSCE Internal (School) | NECO | School |
| NECO — SSCE External / GCE (Private) | NECO | Private/GCE |
| NABTEB — NBC / NTC (School) | NABTEB | School |
| NABTEB — NBC / NTC (Private / GCE) | NABTEB | Private/GCE |

These are explicit labels for the referenced qualification families, not seven independently verified current MAPOLY approvals. SSCE is an examination designation and GCE is not an awarding board. WASC is retained as a legacy certificate label named in MAPOLY's advertisement. Modern school/private terminology is supported by the awarding bodies:

- WAEC school/private WASSCE: https://www.waecnigeria.org/node/9?page=1
- NECO SSCE Internal/External: https://neco.gov.ng/?lang=en
- NABTEB NBC/NTC and its examination series: https://nabteb.gov.ng/
- NABTEB separates O-level and A-level private examinations: https://epins.nabteb.gov.ng/

NABTEB's advanced certificates (ANBC/ANTC), modular certificates, and A-level qualifications are not included in this O’level field. No MAPOLY-specific acceptance evidence was found for NBAIS or Cambridge IGCSE during this research, so they have not been presented as accepted. The previous generic Other option was removed from new input to avoid treating an unverified qualification as accepted; existing history is unchanged.

The API supplies the catalogue and validates board/type combinations, including allowing WASC only with WAEC. Existing WAEC/NECO/NABTEB school/private records keep their original values. No database migration is required. This change does not establish that every pair of examination boards may be combined: combination policies remain demonstration rules pending MAPOLY confirmation.
